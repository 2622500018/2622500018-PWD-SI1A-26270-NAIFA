Kesulitan yang saya alami ketika membuat web jualan ini adalah

- halaman beranda menyatu jadi satu halaman, tidak mau di klik keluar satu halaman yang dituju (untungnya bisa diperbaiki dengan cara, membuat halaman masing masing sesuai dengan isinya seperti index.php untuk beranda awal, biodata.php untuk perkenalan diri saya sendiri sebagai owner, buku-tamu.php untuk mengelola tamu yang berkunjung, menu.php menampilkan menu apa saja yang saya jual ke pelanggan)

- Halaman yang lain sudah ada warna tetapi satu halaman belum memiliki warna, saya agak kesulitan mengubah kode untuk satu halaman ini karna ketika dicoba selalu tidak mau muncul, saya coba terus dengan kode !important berarti " satu kode tersebut terus dipaksa melebihi kode lain", akhirnya bisa meskipun kode yang lain lumayan ketimpa.

-navigasi pada web pebjualan saya berada diatas dikarenakan saya menggunakan pengaturan CSS dengan display flex secara horizontal,untuk membuat perbedaan yang sedikit berbeda dibandingkan teman - teman yang lain

(kalau mau navigasinya ke bawah bukan mendatar kode yang digunakan adalah flex-direction: column, bukan flex-direction: row)
